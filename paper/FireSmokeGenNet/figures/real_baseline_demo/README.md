# Real Stable Diffusion Inpainting demo (genuine inference, scoped)

This folder contains **genuine, reproducible output** from a real, publicly
released model, run with real inference in this session. It is a
feasibility demonstration, **not** a completed Figure 7 / Figure 8 for the
manuscript. Read the scope section below carefully before reusing anything
here.

## What is real here

- **Background** (`inputs/forest_sunrise_512.png`): a real photograph,
  "Forest sunrise.jpg" by Peter Heeling, licensed
  [CC0 1.0](http://creativecommons.org/publicdomain/zero/1.0/deed.en),
  downloaded from Wikimedia Commons
  (`https://commons.wikimedia.org/wiki/File:Forest_sunrise.jpg`) and resized
  to 512x512. The original full-resolution file (15 MB, 4550x2879, EXIF
  shows it was shot on a Nikon D7000 in Oct. 2015) was not committed to this
  repo to keep it lightweight; re-download it from the URL above if needed.
- **Model**: `runwayml/stable-diffusion-inpainting`, a real, public,
  pretrained checkpoint downloaded from the Hugging Face Hub at run time
  (not fabricated, not fine-tuned by us).
- **Inference**: a real forward pass of that model
  (`diffusers.StableDiffusionInpaintPipeline`), run on CPU in this
  environment (no GPU was available). 25 DDPM/PNDM inference steps,
  guidance scale 7.5, seed 42, ~84 seconds of genuine compute
  (see the run command in `run_real_sd_inpainting.py`'s docstring / below).
- **Output** (`outputs/sd_inpainting_real_output.png`): the actual image
  tensor produced by that real forward pass -- not edited, not
  hand-drawn, not generated by a different tool and relabeled.

This genuinely satisfies the "Stable Diffusion / SD-Inpainting" cell of a
baseline-comparison figure, honestly labeled.

## What is NOT real / NOT covered here (important)

- **The mask** (`inputs/handauthored_test_mask_512.png`) is a **hand-authored
  synthetic test shape** (a soft, blob-chain plume outline) created with
  PIL in this session specifically to exercise the pipeline. It is **not**
  a real annotated smoke mask from FLAME, HPWREN, or SMOKE5K, and does not
  represent real smoke geometry statistics.
- **FireSmokeGenNet** does not exist as a trained model (no architecture
  implementation, no checkpoint, no training run has occurred), so this
  demo produces **no** FireSmokeGenNet output. There is nothing to compare
  the SD-Inpainting result against for the manuscript's actual claims.
- **PowerPaint, BLD, and FlameDiffuser** are not run here. Each would need
  its own specific released checkpoint/code wired up the same way
  `run_real_sd_inpainting.py` does for SD-Inpainting; none of that has been
  done.
- **The four FireSmokeGenNet ablation variants** (no-JCA, no-MRDL,
  no-ResNet50, no-filtering) do not exist for the same reason as
  FireSmokeGenNet itself.
- This single example, on its own, does **not** satisfy
  `compose_qualitative_ablation.py` (which needs 5 conditions x N samples,
  all from trained FireSmokeGenNet variants) or
  `compose_qualitative_comparison.py` (which needs all 6 methods across
  4 scenes). It is one cell of one baseline in one hypothetical figure,
  intended only to prove the "real photo + real released checkpoint + real
  inference" pipeline works end to end.

## Multiple samples in one image

Yes -- `run_real_sd_inpainting_multi.py` runs the same real checkpoint
multiple times (different random seeds, same real background/mask) and
tiles the genuine outputs into a single labeled panel
(`outputs/real_sd_inpainting_4samples_panel.png`, 4 samples: seeds 0-3).
This mirrors the manuscript's stated procedure of generating "4 variations
... with different random seeds" per (background, mask) pair -- except
using the real SD-Inpainting baseline instead of the (nonexistent)
FireSmokeGenNet checkpoint. Every panel is an independent, genuine forward
pass; none are duplicated, edited, or synthesized outside the real model.
The individual per-seed outputs are saved under `outputs/multi_seed/`.

## Reproducing this result

```bash
pip install --index-url https://download.pytorch.org/whl/cpu torch
pip install diffusers transformers accelerate safetensors

python run_real_sd_inpainting.py \
    --background inputs/forest_sunrise_512.png \
    --mask inputs/handauthored_test_mask_512.png \
    --output outputs/sd_inpainting_real_output.png \
    --num-inference-steps 25 \
    --resolution 512

# Multiple real samples (different seeds) tiled into one panel:
python run_real_sd_inpainting_multi.py \
    --background inputs/forest_sunrise_512.png \
    --mask inputs/handauthored_test_mask_512.png \
    --output-dir outputs/multi_seed \
    --panel-output outputs/real_sd_inpainting_4samples_panel.png \
    --num-inference-steps 25 \
    --seeds 0 1 2 3
```

Runs in about 1-2 minutes on 4 CPU cores; no GPU required (though a GPU
would allow more steps / higher resolution in less time, closer to the
paper's stated 50-step, 512x512, guidance-7.5 setting used in Table III).

## Path to a real, complete Figure 8

To honestly complete even the baseline row of Figure 8 for one scene, the
same script pattern needs to be repeated with:
1. A real scene/mask pair from FLAME, HPWREN, or SMOKE5K (or another
   consistent source), not a hand-authored placeholder mask.
2. Each of PowerPaint, BLD, and FlameDiffuser's actual released
   checkpoints/code.
3. A real, trained FireSmokeGenNet checkpoint for the "Ours" column --
   which requires implementing and training the architecture described in
   the manuscript (dual-branch ResNet-18/ResNet-50 encoder, Joint
   Cross-Attention, MRDL loss) on a real dataset; nothing here provides
   that.
