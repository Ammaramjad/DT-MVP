# Launch Checklist

## Product Readiness
- [ ] All critical user flows tested end-to-end
- [ ] Error states and retries implemented
- [ ] Billing and subscription lifecycle validated
- [ ] Analytics and attribution events instrumented

## Security
- [ ] Authn/Authz penetration test completed
- [ ] Secrets rotation policy enabled
- [ ] Audit logging enabled for privileged operations
- [ ] Data deletion and export workflows operational

## Infrastructure
- [ ] Autoscaling thresholds tuned
- [ ] Backups + restore tested
- [ ] Alerting rules and on-call runbook in place
- [ ] Blue/green or canary deploy ready

## GTM
- [ ] Landing page + SEO pages published
- [ ] Pricing page and FAQ complete
- [ ] Demo video and docs published
- [ ] Support SLAs defined
