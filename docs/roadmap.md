# Build Roadmap

## Phase 1 — Foundation (implemented in this branch)
- Monorepo setup (web + api)
- Core schema (projects, papers, tasks, citations, chat, subscriptions, audit)
- PDF ingestion + extraction + indexing
- AI summarization / gap finding / reviewer simulation / scoring endpoints
- Dashboard UX baseline
- Dockerized local stack

## Phase 2 — Research Workflow Depth
- Full project manager (folders, milestones, planner boards)
- Rich PDF reader with annotations and bookmarks
- Citation manager with CrossRef/OpenAlex/Semantic Scholar sync
- Advanced RAG chat memory and citation-grounded answers

## Phase 3 — Writing and Publication
- Academic writer section engine
- Literature review matrix and PRISMA generation
- Journal/conference recommender with deadline intelligence
- Reviewer-response drafting tools

## Phase 4 — Team and Enterprise
- Organization workspaces and RBAC
- Admin panel, support desk, billing analytics
- Enterprise security controls (SSO/SAML, audit export, data residency)
- SOC2/GDPR operational controls
